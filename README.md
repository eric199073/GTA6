## 使用地图

下载后，在浏览器打开 `地图/index.html`。地图含14个地点，支持点击展开定位图、文字步骤及原攻略，按未完成、想去、已完成筛选。全境高清图及地点周边高清图块均保存在仓库内。

完成情况与星标只保存在当前浏览器，不会自动跨设备同步。从本地文件切换到外网网址时，原浏览器进度不会自动迁移。

## 外网部署

GitHub Actions 工作流 `.github/workflows/pages.yml` 将 `地图/` 作为网站目录发布。Pages 启用且部署成功后，地址为：

https://eric199073.github.io/GTA6/

仓库设置中需将 Pages 的发布源设为 GitHub Actions。私有仓库能否启用 Pages 取决于账号套餐；此工作流不会修改仓库可见性。

后续向 `main` 推送地图改动，会触发自动更新。手动运行工作流也可重新部署。

新增或移动攻略标记后，在 PowerShell 7 执行 `./地图/更新高清缓存.ps1`，补齐点位周边图块，再一起提交。
